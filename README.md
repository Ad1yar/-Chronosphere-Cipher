🟣 Chronosphere Cipher
"Time is an illusion, and so is your plain text."

Chronosphere Cipher — это скрипт на Python для шифрования текста, вдохновленный персонажем Faceless Void из Dota 2.

В отличие от примитивного шифра Цезаря, алгоритм использует динамическое искажение времени: каждый символ перешифровывается комбинацией байтового XOR-ключа и нелинейного сдвига, зависящего от позиции элемента. В результате один и тот же символ в разных частях сообщения превращается в абсолютно разные знаки.

Особенности

Защита от частотного анализа: Полиалфавитный шифр на базе XOR и динамического сдвига.

Поддержка любых языков: Корректно шифрует кириллицу, латиницу, эмодзи и спецсимволы благодаря UTF-8.

Удобный формат: Выходные данные кодируются в Base64 — их легко копировать и отправлять в мессенджерах.

Интерактивный CLI: Удобный текстовый интерфейс в консоли.
